# Entrevistas

## Entrevista 1

### Perfil

- Nombre: Arq. Carmen Cecilia Valero Escalante.
- Rol: profesora de matemáticas.

### Hallazgos principales

- No está claro qué significa "Análisis numérico"; su interpretación no es la misma para todos.
- Hay debilidades en conocimientos básicos previos y en la capacidad de extraer información de los problemas.
- Se necesita fortalecer la interpretación de problemas.
- El proceso de aprendizaje debe seguir un orden lógico y reforzar el pensamiento lógico.
- Es importante usar lenguaje matemático de forma explícita.

### Necesidades para la herramienta

- Apoyar la corrección de exámenes.
- Generar un resumen de lo importante.
- Escanear información para analizar exámenes.
- Mostrar todo claramente visible.
- Incluir gráficas fáciles de leer y entender.
- Permitir una carga de información sencilla y directa.
- Ofrecer funciones offline tanto para presencial como para distancia.
- Generar reportes resumidos individuales y grupales, con filtros por tema.
- Poder detectar plagio entre compañeros.

### Momento de uso sugerido

- Para el final de la clase.

### Observaciones adicionales

- Todo debe estar claramente identificado por nombre, con parte de análisis y parte escrita.
- Ver cómo cambia la función al jugar con los parámetros puede ser útil para el aprendizaje.

### Elementos deseados en exámenes

- Datos o preguntas propias para el apartado del profesor.
- Estrategias.
- Fórmulas.
- Razonamiento.

## Entrevista 2

### Perfil

- Nombre: xxxxxxxxxxx.
- Rol: profesor de la carrera de arquitectura.

### Problemas y contenido observados

- Los estudiantes entienden resultados, pero no procesos.
- Hace falta refuerzo de conocimientos básicos que ya deberían dominar.
- Se requieren estrategias para resolver problemas.
- Las distracciones afectan el aprendizaje.
- El contenido programático también aparece como frente de atención.
- La gráfica puede servir para indicar lo bueno y lo malo.

### Comentarios útiles para el diseño

- La IA no debe servir para copiar.
- Debe fomentar el pensamiento crítico y el análisis.
- Debe actuar como apoyo, no como reemplazo del trabajo del estudiante.
- En todo caso, la IA debería ayudar a organizar información, no a redactarla.

### Necesidades para la herramienta

- Puede usarse al inicio de una clase.
- Debe servir para seguimiento del equipo y su rendimiento, incluso para ver si entra o no a la página.
- Debe ser amigable para el usuario e intuitiva en su comportamiento.
- Debe permitir procedimientos que el profesor pueda manejar y adaptar según avancen las clases.
- La combinación de colores y las distintas formas de graficar importan.

### Anotaciones del entrevistador

- Conviene indicar una forma de usar la página.
- Al inicio, la herramienta puede cumplir un papel más práctico.
- Al final, puede asumir un papel más teórico.
- Primero debe trabajarse el lenguaje y después el símbolo.
- Puede ser útil un desbloqueo secuencial de herramientas.
- También puede funcionar como refuerzo de conocimientos que luego se vayan a utilizar.

## Entrevista 3

### Perfil

- Nombre: xxxxxxxxxxx.
- Rol: profesor de matemáticas.

### Dificultades detectadas en el aprendizaje

- Contar o cortar la convergencia de la función.
- No saben qué son los números representativos.
- El caso de Colebrook no se puede despejar y debe resolverse con análisis numérico.
- Se cometen errores al momento de resolver.
- Hace falta repasar la parte algebraica.
- Cuesta trabajar el porcentaje de confiabilidad en las campanas de Gauss.
- Es necesario hacer entender los márgenes de error.

### Necesidades pedagógicas

- Incorporar una práctica por fases y luego una práctica completa para comprobar que los conocimientos llegaron.
- Automatizar la corrección de trabajos, preferiblemente con IA.
- Mostrar paso a paso las soluciones.
- Usar gráficas para ampliar el pensamiento mediante la visualización de interacciones.

### Requisitos para la herramienta

- Debe usarse desde el principio para apoyar el seguimiento y fomentar el pensamiento crítico y el avance de los alumnos.
- Debe permitir seguimiento de uso: cuánto tiempo la usan, en qué invierten ese tiempo, qué hicieron y cómo les fue.
- Debe generar reportes.
- Debe tener arquitectura abierta para que el profesor pueda usar comandos.
- Debe ser open source.
- Debe ser accesible, vistosa, amigable y no quedarse colgada.

### Temas de interés

- Geometría.
- Representación gráfica.
- Integración.
